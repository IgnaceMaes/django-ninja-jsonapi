# Body helpers

Helpers for working with `jsonapi_body()` parsed request bodies.

## `get_rel_id()` / `get_rel_ids()`

Extract relationship IDs from a JSON:API body without nested null-checking.

### Problem

```python
# Without helpers — 3 levels of null-checking per relationship
if body.data.relationships:
    rels = body.data.relationships
    if rels.author and rels.author.data:
        author_id = rels.author.data.id
```

### Solution

```python
# With helpers — one line
author_id = body.get_rel_id("author")       # str | None
tag_ids = body.get_rel_ids("tags")           # list[str]
```

Both methods are available on the body model **and** on `body.data`:

```python
body.get_rel_id("author")         # shortcut
body.data.get_rel_id("author")    # equivalent
```

### Example

```python
@api.post("/articles", response=ArticleResource.response())
@ArticleResource.decorator()
def create_article(request, body: ArticleResource.body_create()):
    attrs = body.data.attributes.model_dump()
    article = Article(**attrs)

    author_id = body.get_rel_id("author")
    if author_id:
        article.author_id = author_id

    tag_ids = body.get_rel_ids("tags")
    article.save()
    if tag_ids:
        article.tags.set(tag_ids)

    return article
```

## `apply_attributes()`

Apply JSON:API body attributes to a Django model instance — eliminates PATCH boilerplate.

### Problem

```python
# Repeated in every PATCH endpoint
attrs = body.data.attributes.model_dump(exclude_unset=True)
for key, value in attrs.items():
    setattr(instance, key, value)
instance.save(update_fields=[*attrs.keys(), "updated_dt"])
```

### Solution

```python
from django_ninja_jsonapi import apply_attributes

apply_attributes(instance, body, extra_update_fields=["updated_dt"])
```

### Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `instance` | Django Model | required | The model instance to update |
| `body` | `jsonapi_body()` | required | The parsed JSON:API body |
| `save` | `bool` | `True` | Call `instance.save()` with `update_fields` |
| `extra_update_fields` | `Sequence[str]` | `()` | Additional fields for `update_fields` |
| `exclude` | `set[str]` | `None` | Attribute names to skip |

### Returns

A `dict` of the attributes that were applied.

### Example

```python
@api.patch("/articles/{article_id}", response=ArticleResource.response())
@ArticleResource.decorator()
def update_article(request, article_id: str, body: ArticleResource.body_update()):
    article = Article.objects.get(uuid=article_id)
    applied = apply_attributes(article, body, extra_update_fields=["updated_dt"])
    return article
```

## Generic typed `JsonApiBody[T]`

The body models generated by `jsonapi_body()` are subclasses of `JsonApiBody[T]`, providing full IDE autocomplete and type-checker support.

### Type annotations

```python
from django_ninja_jsonapi import JsonApiBody, JsonApiDataIn

# These generic types are available for type annotations:
body: JsonApiBody[ArticleCreateSchema]
body.data                  # JsonApiDataIn[ArticleCreateSchema]
body.data.attributes       # ArticleCreateSchema — full autocomplete
body.data.attributes.title # str — type checker knows this
```

### isinstance checks

```python
from django_ninja_jsonapi import JsonApiBody

BodyModel = jsonapi_body(ArticleCreateSchema, "articles")
assert issubclass(BodyModel, JsonApiBody)
```
